# 结果在哪里，怎么看

采集 Agent 默认按任务保存结果，不把店铺与团购商品混为一张订单表。CSV 可用 Excel 打开；JSON 用于结构化分析、核对与恢复。

## 先运行虚构演示

```powershell
./setup.ps1
./.venv/Scripts/python.exe -B -m groupbuy agent --demo
```

无需模型 Key、微信或 Reqable。预期为：

```json
{
  "backend": "SCRIPTED_DEMO",
  "status": "COMPLETE",
  "rounds": 8,
  "tool_calls": 7,
  "reported_tokens": 0,
  "prompt_version": "collection-v1"
}
```

默认配置共有 6 项虚构任务，每批 5 项，所以首批完成 5 项、另有 1 项待办。这是预期批次限制，不是漏采。`agent --demo` 每次创建独立演示；要验证同一份任务续跑，使用同一配置运行普通 `run` 两次。

`report_path` 指向本次模型循环报告。网页演示结束后显示相同输出目录。演示中的选择由脚本生成，实际解析和导出由生产工具链执行；完成状态不能作为真实平台或模型能力证明。

2026-10-25 本机实际运行得到 5 个任务目录、共 10 条店铺记录和 10 条商品记录，各任务分页及数据安全检查通过。它们全部来自仓库虚构样例，没有抓取真实平台。

## 目录结构

```text
runtime/agent-demo/<运行编号>/
  progress.json
  outputs/
    agent-runs/<报告编号>.json
    DEMO-001/results/<结果编号>/
      shops.csv
      products.csv
      compact.json
      result.json
      manifest.json
    DEMO-002/results/<结果编号>/...
```

真实网页任务使用 `runtime/ui-workspaces/<工作区编号>/outputs/`，以页面显示路径为准。真实任务文件和诊断日志留在本机；GitHub 只同步代码。

| 文件 | 内容 | 用途 |
|---|---|---|
| `shops.csv` | 每项任务内一行一家店 | 店名、类别、评分、人均、评价数、地址/商圈、可选距离、质量标记与来源 |
| `products.csv` | 每项任务内一行一项公开商品 | 店铺/商品编号、名称、类型、售价、原价、价格单位、销量原文和可见规则 |
| `compact.json` | 按配置选择的精简字段 | 分析或交给自己的程序处理 |
| `result.json` | 内部标准结果、质量与来源 | 校验、恢复与批次合并，不能随意修改 |
| `manifest.json` | 文件 SHA-256 与任务关联 | 检测结果被改动或不完整 |

示例表格（仅示意，全部虚构）：

| 店铺编号 | 店铺名 | 评分 | 人均价格 | 原始单位 |
|---|---|---|---|---|
| fictional-shop-1 | 虚构餐厅1（示例店） | 4.8 | ¥80/人 | CNY |

字段单位和原文以实际导出为准。未知值留空；不根据套餐名称推断人数、可用时间或店铺位置。销量的 `+`、价格单位与距离中心需保留。

## 怎么判断是真完成

逐项检查：任务与目标一致；搜索、筛选、终页证据齐全；分页没有缺口或冲突；店铺与商品关联有效；安全检查通过；结果清单已写入并通过恢复校验。模型说“完成”、API 测试通过、上报连接成功或滚动次数耗尽都不能替代这些条件。

第一项真实任务需人工比对店名、价格、销量原文、类别与范围。通过后再验证每批 5 项，最后考虑定时。跨任务遇到同一店铺会保留其各次观察，不能直接当成多家不同店。

## 把项目交给同学

1. 发仓库链接，让对方按 README 在 D 盘安装并运行演示。
2. 对方使用自己的微信、Reqable 和模型 Key，校准自己的窗口、城市、中心与筛选。
3. 先做一个任务并核对上述结果，再扩大批次；CLI 与网页不同时运行。
4. 分享代码更新；真实结果按研究/课程的数据管理约定在仓库之外交接。CSV 不包含完整恢复状态，换电脑续跑不能只复制 CSV。

自动化助手可以参考 [`groupbuy-collection` skill](../skills/groupbuy-collection/SKILL.md)，也可直接阅读步骤。普通使用者不需要安装 Codex、MCP 或任何 skill。
