# 一键模拟完整链路

无需模型 Key、微信、Reqable 或 Windows 界面依赖。适合第一次安装、同学交接和发布前自检。模拟只使用 `127.0.0.1` 临时服务，不读取环境中的模型密钥或代理，不操作桌面，不修改工作台原任务。

## 怎样运行

在项目目录运行：

```powershell
./setup.ps1
./.venv/Scripts/python.exe -B -m groupbuy simulate
```

也可以执行 `./start-ui.ps1`，打开工作台后点击 **模拟完整链路**。模拟支持“停止”，在当前安全操作边界生效。结果单独显示，不会把真实任务改为完成。

成功返回 `status: PASS`、`backend: SIMULATED_RESPONSES_SSE`、`cases_passed: 12`。失败返回非零退出码。每次运行生成独立的 `runtime/simulations/<运行编号>/`，不覆盖上次结果。

## 哪些部分实际执行

```text
确定性的虚构规划器
  → 本机 Responses HTTP/SSE 服务
  → 项目实际请求编码、SSE 解码和 Agent 工具循环
  → 虚构界面观察、搜索与滚动
  → 本机 Gzip HAR 报告 POST
  → 实际接收器、字段投影、任务时间窗
  → 分页、去重、关联、脱敏
  → CSV / JSON / 完整性清单
  → 进度保存、续批与显式重试
```

模型决策、界面和数据是模拟；HTTP/SSE、HTTP/Gzip、工具门禁、解析、导出和恢复代码实际执行。没有访问平台私有接口或外部模型，也没有真实 OCR、桌面点击、Reqable 进程操作。这不能证明真实账号可用、模型规划可靠或真实采集成功。

## 验收条件

| 检查场景 | 预期行为 |
|---|---|
| 分批与续跑 | 首批完成 5 项，第 6 项待办；续跑后共 6 项、12 家虚构店铺、12 个商品 |
| 没有上报 | 阻止完成，不伪造本地输入 |
| 上传地址错误 | HTTP 403，不能密封 HAR 或完成任务 |
| 缺页 | 阻止导出；修复后显式重试，重新搜索并完成 |
| 验证或限制 | 搜索前停止 |
| 页面网络错误 | 搜索前停止，不自动换账号或网络 |
| 持续加载 | 等待预算耗尽后停止 |
| 失焦 | 停止，不向其他窗口输入 |
| 错误目标 | 阻止确认和完成 |
| 滚动上限 | 不作终页，分段仍无法到底时停止 |
| 模型 SSE 未完成 | 不执行未确认的工具调用 |
| 模型空转 | 有界停止，返回 agent_no_progress |

正常场景合计 18 次本机报告 POST、24 次本机模型请求、22 次工具调用。每项包含一个重复页；6 次重复页不增加导出记录。店铺与商品关联、分页与脱敏均须通过。这是确定性回归数据，不是模型性能基准。

## 文件与结果

- `report.md`：可读汇总。
- `report.json`：各场景结果、受控错误码、计数、产物相对路径。
- `batch_and_resume/runtime/outputs/SIM-001/results/<编号>/`：首项的 shops.csv、products.csv、compact.json、result.json、manifest.json。
- 其余场景目录：独立进度与本地投影输入，用于检查停止与恢复。

这些运行产物只在本机生成，不能提交 GitHub。公开仓库只包含模拟实现、虚构样例、测试和说明。模拟通过后，真实采集仍须分别核对模型、Reqable 上报、地点中心、筛选、终页和完整分页。
