# 平台适配器

接口定义在 groupbuy/adapters/base.py。通用调度器只处理任务、状态、输入时间窗口、结果和清单，不读取任何平台字段或像素坐标。

| 职责 | 大众点评实现 |
|---|---|
| collect_ui | ui_flow 搜索、筛选、观察列表、滚动、终页、续段校验 |
| validate_evidence | 任务哈希、查询/目标/筛选、显式终页、窗口/帧、时间门禁 |
| parse | data.list/shopInfo 业务投影，商品与店铺关联，字段来源 |
| select_pages | 最新轮次、重复页去重、从游标 0 到显式 isEnd 的完整链 |

WindowsDriver 提供观察、当前 OCR 匹配点击、输入、滚轮和等待；它只在显式 ui/live 操作时加载第三方依赖。每次输入都检查窗口前台、遮挡与当前画面。UI 标签与响应规则由平台适配器和本机 profile 管理。

第一版分页采取保守策略：即使响应看似重复第一页，未被独立证实的服务端游标回退也会拒绝。它没有移植旧流程中特定捕获的游标修复特例。冲突重复页、无请求起点、无明确 isEnd、链外孤立页都会停止；最新搜索轮次不完整时不会回退到上一轮完整数据。

新增平台时，提供新的适配器、schema 样例、字段来源与价格单位规则，注册到 get_adapter，并加入任务隔离/完整分页/冲突/隐私测试。未经实现和实机验证，不添加平台支持宣传。当前注册表只有 dianping。

范围限制：商品使用规则只能来自已捕获可见文本；不会推断未出现的规则，不自动进入支付、购买订单或核销页面，不实现私有接口客户端或验证绕过。店铺 ID 缺失会进入停止核验；缺商品 ID 保持 null 并加质量标记。分类仅使用业务类别，不凭商家名字判定食品类别。
