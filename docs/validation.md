55 项 unittest 均通过。测试覆盖任务隔离、完整分页、重复页与冲突、最新轮次不完整、缺失 ID、商品店铺关联、食品零售分类、价格单位和“+”原文、未知距离中心、脱敏、公式文本、分段续滚、失焦、验证码停止、批次恢复和合并、定时时间槽以及三种 Git 扫描面。还验证了非布尔终页值、字符串伪确认和人工中断后不能复用旧界面证据。

另执行真实 CLI 离线演示：6 项虚构任务，首批 5 项、次批 1 项、第三次 0 项；合并得到 6 个任务、12 条店铺观察、12 条商品观察。CLI 与前台调度共用同一执行器。定时验证采用受控时间，没有等待全天，也没有在本机激活定时服务。

关键限制：第一版只解析公开搜索列表里出现的商品；未自动进入商品详情或商家详情，缺少的规则保持空值。Reqable 导出仍由操作者完成。OCR 标签、目标定位及列表锚点必须在每台机器验证。存储清单用于完整性和误操作防护，UI 哈希不是不可伪造的签名。隐私扫描有规则覆盖范围，不能替代白名单人工审查。

发布检查的实际统计见 docs/release-report.json。原始验证产物放在仓库外，不提交采集数据或运行日志。
