本版测试覆盖真实回环 HTTP 接收、未授权地址、无请求、格式异常、无任务探测、Gzip、无密钥执行、校准拦截和缺失依赖零模型请求。界面控件变化时保留风险、窗口及遮挡检查；滚动预算不等于终页。

历史人工 UI 调试仅证明已安装本机 OCR、能进入搜索与分类菜单。它没有验证指定地点中心与半径、真实终页/分页和最终导出。搜索关键词不能证明定位已经切换，页面没有的半径不能直接填成已支持。

自动化验证使用虚构任务、模拟模型和界面。离线演示标记为 SCRIPTED_DEMO；上报探测成功标记为 CAPTURE_CONNECTED，并明确 collection_verified=false。两者都不能更新真实任务为完成。模型原文、账号凭据、抓包内容、真实任务和诊断截图不进入仓库。

远程 Windows/Linux CI 以当前提交对应的 GitHub Actions 为准；核心测试不等同于微信 GUI 自动化验证。发布扫描统计见 [release-report.json](release-report.json)，首次使用见 [六步教程](first-run.md)。
