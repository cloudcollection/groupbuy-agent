# 实现与验证状态

2026-10-07，Windows 本机。0.3.0 工程提供独立 OpenAI Agent、CLI、网页及 Reqable 官方报告服务器接收器。本次发布前使用虚构业务数据、模拟窗口/模型及真实回环 HTTP 验证；未恢复旧采集任务，未发出真实模型请求，未抓取新平台流量。远程 CI 以本次提交对应的 GitHub Actions 结果为准，旧版 CI 不能证明新功能已经通过远程验证。

110 项 unittest 通过。另执行 CLI agent --demo，真实解析/导出 5 项虚构任务；前端 JavaScript 语法与 Git 差异检查通过。离线演示由脚本模拟模型，不证明真实模型可用。测试服务只监听本机，不访问平台接口。

网页服务已在本机启动并通过 HTTP 测试。内置浏览器控制工具初始化受 Windows 沙箱错误阻止，随后使用 Playwright CLI 与已安装的 Edge 完成桌面 1440×1100、窄屏 390×844 的截图检查；页面计数与控件正常展示。原生电脑控制工具未能初始化，因此本次未执行真实微信或 Reqable UI 操作。检测到的 Reqable 版本为 3.2.15，版本支持报告服务器不等于联动已经验证。

边界：仅解析搜索列表公开商品，不自动进入详情页；未展示的规则留空。Reqable 的首次报告规则、平台抓包与模型网络隔离由操作者配置。界面必须能观察到城市、目标及筛选，否则停止。UI 帧哈希与数据清单用于完整性检查，不是不可伪造的签名。隐私扫描有规则覆盖范围，需要人工复核发布白名单。

本地发布扫描统计见 [release-report.json](release-report.json)。配置、捕获文件、采集结果及日志保留在被忽略的 runtime，不能进入 Git。只在明确发布指令后推送。
